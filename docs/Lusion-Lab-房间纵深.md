# Lusion Lab · 房间纵深

日期：2026-11-02  
触发：G0 由你确认「房间纵深」→ 进入计划 Day 3–4。  
范围：只加**一个**空间元素，不扩场景、不加第二个 3D 物体、不加新依赖/媒体。

## 1. 做了什么

在原来「3D 人像 + 金框 + 圆环 + 尘埃」的基础上，加了一组**地面 + 反射 + 阴影**：

- 照片下移/缩小，底部离开屏幕边缘；
- 照片下方 1px 金色地面线；
- 同一张人像纹理的**镜像反射**：ShaderMaterial 翻转 UV + 向地面渐隐；
- 地面暗色透明层，让照片像立在一个空间里；
- 照片落地处的柔和阴影。

**只加了一组空间元素**，没有第二个物体、没有音频、没有新图片请求。

## 2. 构图变化

| 项目 | 改动 |
|---|---|
| 相机 z | 6.2 → 7.2，照片变小、留出地面 |
| 照片 y | 0 → 0.35，底部离地 |
| 地面线 | y=-1.42，金色 1px |
| 反射 | 照片下方，同一纹理，透明度 .27，向下渐隐 |
| 阴影 | 照片落点，径向渐变黑色，低透明度 |
| 地面层 | 9×7 暗色透明平面，给反射一个“面” |

照片仍是右侧主体，左侧导航不变；点击、CTA、OPEN 光标、static/reduced 降级不变。

## 3. 性能

| 场景 | FPS | p95 |
|---|---|---|
| 1440 DPR1 | 60.2 | 16.8ms |
| 1440 DPR2 | 60.3 | 16.7ms |
| 1920 DPR1 | 60.2 | 16.7ms |

- 加反射/阴影后仍是 ~60fps（headless Chrome，真实 GPU/低端机另测）。
- 没有新增图片/依赖；反射复用同一张 texture。
- 反射 plane 与阴影/地面层在卸载时 dispose。

## 4. 视觉结果

- 3D 照片从“浮在屏幕上”变成“立在一条地面线上”；
- 底部有可辨认的镜像和落影，第一眼更像一个**私人放映室**；
- 金色圆环变成背景光环，不再只是相框装饰；
- 但仍然是“单张人像 + 一个地面”，距离 Lusion 的完整场景还远。

## 7. 对“仍像相框”的最后一版（2026-11-02）

你的判断是对的：上一版虽然有地面/反射，但背景仍是纯黑渐变、照片正面朝前，所以还是“相框”。

这次**不再加第二个物体**，只做计划里的“调光/构图”：

- 加一面**后墙**（暖黑渐变 + 墙面光池）；
- 加一块可见的**地面**，与墙形成地平线；
- 人像平面转 **6°**，露出薄框侧面；
- 加**薄框厚度**（BoxGeometry），照片不再是零厚度贴片；
- 保留地面线、镜像反射、落影；
- 光池在后墙，照片与框有前后关系。

结果：

- 第一眼从“黑底相框”变成“暗房间里的 framed portrait”；
- 但**仍然是一张带框的人像**，不是 Lusion 的完整空间叙事；
- 这是最后一次构图/光调整，**不再加几何**。

性能：1440 DPR1/DPR2、1920 仍 ~60fps；完整 e2e **35/35**、check 47、build 通过。
