# After Hours · 动态效果优化

日期：2026-11-02  
状态：**P0 + P1 + P2 已实施（2026-11-02）；内容/发布未完成**。
范围：`/` After Hours 首页与 `/?experience=light-gallery` 人像导航页；目标是让导航页在 3 秒内更有记忆点，同时把注意力引向主入口，提升外跳点击与回访。

## 0. 结论

现在的动效**不差，但不够“被记住”**：入场、姓名扫光、hover、V06 选中都被控制在 200–700ms、1–8px 的幅度内，像高级 UI 的细节，不像一个个人品牌的“开场”。要提升引流，不需要把全站变成动效演示；需要 **一个明显的签名动作 + 三个辅助动作**：

> **推荐组合：Cinematic Portrait（电影感人像开场）+ Contact Sheet（接触印相式照片条）+ Open Cursor（桌面 “OPEN” 光标）。**

- **签名**：18+ 确认后的一次性“开幕”——黑场/金线/人像遮罩/姓名逐字/主入口亮起，约 **800–900ms**，每会话一次，可跳过。
- **辅助 1**：人像与文字的 **6–10px 指针视差**，只桌面精细指针；移动端静态。
- **辅助 2**：主入口的 **一次金色呼吸 + 磁性跟随**，指向唯一 CTA，不做无限闪烁。
- **辅助 3**：照片条从“静态缩略图”变成 **接触印相/轻 coverflow**；选中照片短金线、相邻退后，原生滑动不变。
- **可选**：桌面 “OPEN” 光标、滚动时章节线绘制、分享海报；都排在签名动作之后。

先做 **P0 的 4 个动作**，不要一次上 10 个。一次性看 10 个动效，用户记不住任何一个。

## 1. 现状诊断

### 已有

| 层 | 现状 | 评价 |
|---|---|---|
| 首屏 | 光廊左栏 700ms 内入场，身份/入口错峰 | 快、稳，但幅度小，像 UI 渐入 |
| 姓名 | 120%→32% 暖金扫光，600ms 后开始 | 好看，但发生在首屏后段，缺少“被看见”的瞬间 |
| 导航 | 1+4，主入口只有静态金边/圆环 | 主次清楚，但没有“现在点这里”的动作 |
| 照片条 | 原生滑动 + V06 短金线/标题提亮/计数 | 选中提示已足够清楚，整体仍偏静态 |
| 弹层 | 180ms 淡入 + 8px | 合格，不是引流关键 |
| 移动端 | 环境光静止、照片条原生滑动 | 稳，但缺少手机上的“一个亮点” |

### 为什么“不够”

1. **缺少一个 3 秒记忆点**。现有动效都是“状态变化”，没有一个只属于这个页面的 signature。
2. **视线没有被引导到主入口**。主入口和次入口的动效差异只有金边/圆环；用户的眼睛没有“被拉过去”的理由。
3. **人像只是背景**。已有 pointer light，但没有纵深/遮罩/呼吸；人物没有“活起来”。
4. **照片条是平的**。缩略图并排、选中一条线；没有封面感、没有相邻关系、没有指尖惯性。
5. **页面太安静**。安静是品牌的一部分，但安静需要**一次有控制的爆发**来对比；现在只有安静。
6. **缺少“分享/再看一次”的动机**。导航页天然是一次性点击页；没有让人截图、收藏、回访的动作。

## 2. 目标与原则

### 引流目标

1. **3 秒内**：知道这是谁、看哪里、为什么点。
2. **1 次主点击**：把注意力集中到一个主入口（优先 Telegram）。
3. **愿意多看**：照片条/照片详情让人停留 >15 秒。
4. **愿意传播**：有一个可截图/可分享的“海报时刻”。
5. **不牺牲**：可读性、加载、可访问性、减少动态。

### 动效原则

- **少而大**：一个签名动作，三个辅助；其余保持静态。
- **慢入快出**：进入 420–700ms，退出 160–240ms；按压 70ms。
- **只动 transform/opacity/clip-path**；不动 width/height/top/left；不用持续 rAF。
- **一次只让一个东西发光**；金色预算继续遵守。
- **动效必须可跳过、可暂停、可减少**；`prefers-reduced-motion` 直接终态。
- **不延迟内容**：首屏文字 300ms 内可读；任何开幕最多 900ms，且点击/键盘/滚动可立即跳过。
- **不新增媒体请求**：维持 2 张 `<img>` / 2 个媒体请求；LQIP 已在内联数据里。
- **移动端不是桌面缩小版**：不做视差、不做自定义光标；只保留入场 + 主入口一次呼吸 + 照片条。

### 审美方向

**关键词**：After Hours、私人放映、接触印相、香槟金、黑场、电影字幕、纸张颗粒。  
**不是**：霓虹紫、玻璃拟态、漂浮粒子、3D 球体、通用“AI 黑金”。

![墨黑香槟参考](../design-references/2026-10-29-Linktree-御姐风/01-墨黑香槟-v4.png)

参考方向（只借结构，不抄皮）：

- [Awwwards · Mat Voyce 的 kinetic type 案例](https://www.awwwards.com/case-study-mat-voyce-designing-a-digital-home-for-a-kinetic-creative.html)：字体作为主视觉，而不是装饰。
- [Awwwards · Jesper Landberg](https://www.awwwards.com/jesperlandberg/awards)：克制的深色、空间和光标。
- [Lusion](https://lusion.co)：沉浸式人像/空间，但**不引入 WebGL**，只借“纵深”和“节奏”。
- [GSAP ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/)、[SplitText](https://gsap.com/docs/v3/Plugins/SplitText/)、[Flip](https://gsap.com/docs/v3/Plugins/Flip/)：实现手段。

## 3. 推荐方案：Cinematic Portrait + Contact Sheet

### 3.1 三秒分镜（光廊，首次确认后）

| 时间 | 画面 | 动作 |
|---|---|---|
| 0ms | 18+ 按钮按下 | 页面内容已在背后就绪；不白屏 |
| 0–120ms | 黑场/暖黑遮罩 | 1px 金线从左下向上画 0→100% |
| 100–520ms | 人像 | `clip-path` 从右向左揭开；scale 1.045→1；轻微去模糊 |
| 260–620ms | 姓名 | 逐字 y 26→0、opacity、轻微 rotateX 4°；金色扫光接上现有的 32% 终态 |
| 420–680ms | 五个入口 | 25–30ms 错峰；主入口先亮，次入口后到 |
| 600–860ms | 主入口 | 一次 1.6s 金色呼吸 + 圆环亮起；不是无限闪 |
| 700–900ms | 页脚/照片条 | 收尾；scroll hint 出现一次 |
| 900ms | — | 所有遮罩可交互；重复访问直接跳过 |

**限制**：首屏文字 300ms 内已经可读；遮罩不拦截点击超过 900ms；`pointerdown`/`keydown`/`wheel` 可提前结束；`sessionStorage` 记住“已看过”，刷新不重播；减少动态/静态直接终态。

### 3.2 人像纵深（P0）

- 桌面精细指针：人像 `x/y ±8px`、文字反向 `±2px`、照片 `scale 1.02`；`gsap.quickTo`，600ms 阻尼。
- 只有 `(hover:hover) and (pointer:fine)` 且宽度 >900；移动/平板不做视差。
- 离屏/隐藏标签页暂停；不新增持续 rAF；不改变图片布局。
- 保留现有的背景定位、比例和右侧构图；只动 `transform`。

### 3.3 姓名（P0）

- 用 `SplitText`（GSAP 3.15 已包含）按**字素**拆，不要按汉字部件拆；给 h1 保留 `aria-label`，拆出的字符 `aria-hidden`。
- 逐字 `y 26 → 0`、`opacity 0 → 1`、`rotateX 4° → 0`，30–35ms 错峰；总 600ms 内。
- 现有 120%→32% 扫光放到逐字完成后，保持 32% 终态；不要二次永久改变明度。
- hover 时单字 1px 上浮 + 金色 80ms；不做整段抖动。

### 3.4 主入口 CTA（P0）

- 只对 D1 选出的**唯一主入口**做动作；没有可用主入口时不做。
- 一次“金色呼吸”：`box-shadow`/`::before` 亮度 0→0.6→0，1.6s，延迟 1.2s，播放一次；之后停止。
- 磁性：指针在按钮 80px 内，按钮 `x/y` 最多 4–6px；离开回 0；`quickTo`。
- hover：金色下划线 240ms、箭头 2px；按压 `.985` 70ms；松开 220ms。
- 移动端：只保留一次呼吸 + 按压；不做磁性。
- 目的：让用户的眼睛在 3 秒内落在唯一主入口，而不是五个入口平均。

### 3.5 照片条 Contact Sheet（P1）

- 选中照片：`scale 1.03`、`translateY(-3px)`、金边；相邻 `scale .96`、`opacity .62`；400ms。
- 桌面 hover：图片 `scale 1.04`、caption 提亮、底部 24px 金线；不推动布局。
- 轻 coverflow：相邻照片 `rotateY ±3°`、`z -20px`；只桌面，移动端不做 3D。
- 拖拽/轻扫：保留原生 scroll-snap；可选 `Observer` + `quickTo` 做惯性，不重写原生滚动。
- 不做自动轮播；自动轮播会让用户来不及看，也会和“私人收藏”的气质冲突。

### 3.6 章节滚动（P1，首页）

- “A STUDY IN CONTRAST” 上方 1px 金线从 0→100% 画开；`The lookbook.` 用遮罩上移 12px。
- 照片按 40–50ms 错峰进入；只做一次；不 pin、不劫持滚动。
- 滚动进度只做 1px 顶线或章节线，不做全屏进度条。

### 3.7 桌面 “OPEN” 光标（P1，已实施）

- 6px 金点 + 32px 细环；hover 到入口/照片时，环放大、出现 `OPEN` / `VIEW` 小字。
- 只桌面精细指针；触摸、键盘、减少动态不启用；`cursor: none` 只在自定义光标成功挂载后设置，避免无光标。
- 这是“高级感”最快的来源之一，但不要让它遮挡文字；环 32px，不做大块跟随。

### 3.8 分享海报（P2，可选）

- 一个不显眼的“保存这张”/“分享”入口：把当前照片、姓名、站点短链、QR 生成 1080×1350 海报。
- 用 Canvas 绘制，复用已加载的图片/字体；不新增媒体请求；不生成假人脸。
- 分享海报是最直接的引流资产：用户发到 Telegram/X 时自带入口。
- 如果时间不够，先做“复制链接 + 原生分享”，不做完整海报。

## 4. 动效语法

### 时长

| 场景 | 时长 |
|---|---|
| 按压 | 70ms |
| 释放/回弹 | 200–220ms |
| hover 底色/下划线 | 160 / 240ms |
| 入口/文字入场 | 420–600ms |
| 签名开幕 | 800–900ms |
| 照片选中 | 300–400ms |
| 弹层 | 180ms 开 / 120ms 关 |
| 滚动章节 | 500–700ms，一次性 |

### 缓动

- 进入：`cubic-bezier(.16,1,.3,1)`（现有 `--public-ease-out`）
- 退出/按压：`cubic-bezier(.2,.75,.3,1)`
- 扫光：`sine.inOut`
- 不做 bounce/elastic；不做无限 yoyo（环境光除外，且桌面限定）。

### 金色预算

全页仍只保留：
1. 姓名；
2. 唯一主入口；
3. 键盘焦点；
4. **选中照片短金线**（V06 已加，属于照片状态，不额外扩散）。

不要把金色加到：所有 hover、所有图标、所有数字、所有边框、光标拖尾。

### 可访问性

- `prefers-reduced-motion: reduce`：无位移、无遮罩、无扫光、无光标；直接终态。
- 静态浏览：与减少动态一致；保留颜色/焦点/选中。
- 自定义光标：触摸/键盘自动隐藏，焦点环 2px 保留。
- 不使用闪烁 >3Hz；不做自动播放音频；不做必须动效才能操作。
- 所有入口仍可 Tab、Enter、Escape；弹层焦点返回不变。

## 5. 不做什么

- ❌ 全屏 WebGL 粒子/3D 球体/流体——与“私人放映”无关，移动端代价高。
- ❌ 自动轮播照片、无限 marquee——用户来不及看，且会抢主入口。
- ❌ 滚动劫持/全屏 pin 的导航页——链接页应该 1–2 屏内完成选择。
- ❌ 全站自定义光标没有 fallback——触摸/键盘/低端机直接坏。
- ❌ 每个入口都发光/浮动——金色预算崩溃，主次消失。
- ❌ 无限呼吸/闪烁 CTA——会显得廉价，也会让用户焦虑。
- ❌ 动画 width/height/filter/blur——掉帧；LQIP 的 blur 是静态层，不参与动画。
- ❌ 为了动效新增 npm 依赖/第三个媒体请求——现有 GSAP 已够。
- ❌ 让开幕挡住链接超过 900ms——引流页最忌讳“先看我表演”。

## 6. 适合的 Skills / Harness 插件

### 6.1 当前可用的

**DSH 当前 skill catalog** 只有 Office 系列（docx/xlsx/pptx/pdf 等），**没有网页动效/审美 skill**。`~/.dsh/plugins` 目前只有 `dsh-startup-secret`（启动验证），与审美无关；没有发现可直接安装的 DSH 设计插件。

但本机 `~/.codex/skills/` 有非常合适的参考与实现技能（不是 DSH `skill` 工具自动加载，需阅读/移植其方法）：

| Skill | 位置 | 适配度 | 怎么用 |
|---|---|---|---|
| **`ui2v-motions`** | `~/.codex/skills/ui2v-motions` | 高（动效词汇） | 1,262 个 GSAP 动效包；只当**选型索引/镜头参考**，选 5–6 个动作，不引入 616MB 或 1920 视频素材 |
| **`card-theater`** | `~/.codex/skills/card-theater` | 中高（照片条） | 借 coverflow/选中展开/相邻退后的**关系**；不引入 Swiper/3D 大依赖 |
| **`gsap-timeline` / `gsap-scrolltrigger` / `gsap-plugins` / `gsap-performance` / `gsap-core` / `gsap-react`** | `~/.codex/skills/gsap-*` | 高（实现） | 直接照官方模式：timeline、SplitText、Flip、Observer、ScrollTrigger、useGSAP、quickTo |
| **`swiss-shot-demos`** | `~/.codex/skills/swiss-shot-demos` | 中（克制） | 借“图表/排版优先、禁油光、动画快进快停”；不借纸白/橙色 palette |
| **`video-shot-demos`** | `~/.codex/skills/video-shot-demos` | 中（镜头语言） | 只借开场/转场的镜头结构；不做视频 |
| **`imagegen`** | `~/.codex/skills/.system/imagegen` | 低–中（可选） | 只在需要静态纸张/胶片纹理/海报底图时用；不生成人物脸部，不替换真实照片 |
| **`review-agent`** | `~/.codex/skills/.system/review-agent` | 高（QA） | 实现后做只读代码审查，不替代视觉审查 |

**具体可借的 UI2V 动效**（只借节奏，不复制 1920×1080 素材）：

- `bottom-up-letters` / `text-stagger`：姓名逐字。
- `hero-split-wipe`：开幕遮罩。
- `iris-reveal`：替代方案（金圈/光圈），但本项目更适合“金线+遮罩”。
- `grid-card-assemble`：五入口错峰组装的参考。
- `kinetic-type-swap`：姓名的备选（不要真的换词）。
- `coverflow-classic`（card-theater）：照片条选中关系。

### 6.2 候选外部 skill

- **`awwwards-3d`**（SkillsMP 上的第三方 Agent Skill）是一个候选，用于 3D 网站参考；但它**未安装、未审计**，且本项目不建议引入 WebGL/3D 重依赖。只作为 mood reference，不装进生产。
- **`premium-navigation`** 是 Framer 组件，不是当前 Next.js/GSAP 技术栈；不适用。
- **`hyperframes`** 是 HTML→MP4 渲染，不是网页运行时；不适用。
- **`dynamic-archify`** 是架构图；不适用。
- **`video-qa-frameproof`** 是视频帧 QA，不是网页；不适用。

### 6.3 结论

**最合适的不是新插件，而是已有的 `gsap-*` + `ui2v-motions` 选型 + `card-theater` 的选中关系 + `swiss-shot-demos` 的克制。**  
不新增 npm 包：现有 `gsap@3.15` 已包含 SplitText、Flip、Observer、ScrollTrigger；`@gsap/react` 已在用。`three` 虽已安装，但当前人像页没有 WebGL 路径，不建议重新引入。

> 如果希望 DSH 内直接调用这些 skill，需要把 `~/.codex/skills/gsap-*` 与 `ui2v-motions` 注册到 DSH skill 目录；这是工具链工作，不是产品运行依赖。当前先按文档阅读/移植即可。

## 8. 验证与实验

### 视觉/技术验收

- 1440×1000、1440×700、390×844、320×568 截图：开幕 300/700/900ms；reduced；静态；主入口 hover/press。

## 9. 风险与边界

- **开幕越长，越可能挡住点击**：硬上限 900ms，可跳过，重复访问不播。
- **暗色 + 动效容易显“油”**：只动 transform/opacity/clip-path；不加霓虹、玻璃、粒子。
- **移动端性能**：不做视差/coverflow/自定义光标；只保留入场 + 一次呼吸。
- **主入口不存在时**（本地草稿全停用时）：不要给次入口伪造“主 CTA”呼吸；没有主入口就不做。
- **生产链接/发布仍未配置**：动效不能替代内容；LQIP/2500 也仍是本地草稿。引流效果最终取决于真实外链、更新频率与内容。
- **审美是判断题**：P0 做完先给 3 个静态帧（0/300/900ms）和一段 6 秒录屏，确认“像 After Hours”再继续 P1。
