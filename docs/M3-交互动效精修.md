# M3 · 按钮、照片切换与移动端动效精修

日期：2026-10-30。已应用到本机工程，未发布或部署。

## 当前页面与采用的技能

当前默认首页为 After Hours，带五入口和照片条；`/?experience=light-gallery` 已在上一轮改为右侧人像背景与左侧紧凑导航。本轮以实际源码为准，保留这一现状。

- `ui2v-motions`：参考短按压、回弹的节奏，重写为现有按钮 CSS，没有引入其视频画布、CDN 或素材包。
- `card-theater`：借鉴选中照片强调、明确导航反馈；沿用默认首页原生照片条。
- `gsap-react`、`gsap-performance`：组件作用域、动画清理、减少持续渲染及不可见时暂停。
- 当前人像预览不再使用 ScrollTrigger / Three.js；本轮没有重新引入它们。

## 改动

1. **按钮**：有效入口鼠标悬停上移 1px、香槟掠光、箭头提示；按压约 70ms，缩至 98.5%，释放回弹。触屏只保留按压反馈。确认按钮与照片前后按钮同步处理；键盘焦点为清晰的 2px 描边；停用入口不产生可点击假象。静态模式和系统减少动态保留颜色与焦点，关闭位移。
2. **照片切换**：按照片实际中心缓存滚动锚点，配合原生居中吸附；同步选择 ref 处理快速连续输入。主动选片持续保留，新的触摸或滚轮操作接管；方向键、Home/End、缩放与后台预览统一处理。滚动事件每帧合并，不在每次滚动里重新测量所有照片；观察器与回调随卸载清理。图片使用异步解码。
3. **移动端**：持续环境光限宽屏精细指针设备；手机保留相同静态灯光、入场与照片显现。人像导航姓名由 7 秒无限循环改为 2.2 秒单次扫光，手动重新启用后再播放一次。离屏、隐藏标签页暂停相应动画。

以上为桌面 Chrome 与手机尺寸模拟，尚未测量真实手机帧率或耗电；本轮确认减少持续动画和正确的可见性行为，不据此宣称具体 FPS 提升。没有新增运行依赖，也没有更新站点配置、发布指针、照片或真实外链。
