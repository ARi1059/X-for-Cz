# 「教父」IP 宇宙设定 v1

制定日期：2026-11-10；本轮已确认整体采用  
状态：品牌与内容架构基线；账号注册、用户名占用、实际频道配置仍需单独落实。  
适用范围：X 主号、Telegram 频道与机器人、导航页、后续社区矩阵。

## 1. 一句话定位

**教父主理的成年女性风格影像档案：每位主角，各自成章。**

由男性主理人「教父」作为统一的策划者、拍摄者和叙事者，持续呈现多位成年女性各自鲜明的风格企划。主号先聚焦一个核心账号和稳定内容；初创期不安排客座共创。每位女主的造型、气质和系列表达从本人特点出发，不强行套用统一人设。

这里的“教父”是品牌角色与内容主理人，不是对出镜者的所有权声明。出镜者是作品的共同创作者，公开使用经本人确认的艺名与系列信息。

## 2. 世界观

### 核心概念

整套 IP 采用**西西里黑色电影式的虚构档案宇宙**：夜色、旧档案、封蜡、密钥、港口航线与安全屋构成视觉语言。叙事重点是“作品如何被发现、策划、记录、保存与解锁”，不是现实犯罪活动。

### 世界中的角色

| 角色/概念 | IP 含义 | 对应现实功能 |
|---|---|---|
| 教父 | 主理人、策展人、档案讲述者 | 运营主号，策划内容与系列 |
| 女主 / 主角 | 每个系列的中心人物，各有独立风格 | 成年出镜者；风格由本人特点出发 |
| 档案 | 按人物与系列整理的作品目录 | 预告、作品索引、会员内容目录 |
| 缄默法则 | 进入会员档案后的私密叙事规则 | 会员内容区的品牌概念 |
| 通行证 | 经用户主动获取的访问凭证 | VIP 付费机器人与会员开通流程 |
| 走私船 | 在虚构叙事中运送“档案”的载体 | 资源存储与媒体分发机器人 |
| 线人 | 连接读者与主理人的通讯角色 | 双向机器人、问询与通知 |
| 安全屋 | 入口变更时仍可找到品牌的据点 | 防丢频道、恢复入口公告 |

### 叙事基调

- 克制、神秘、有秩序；用档案、编号和暗号营造连续感。
- “教父”负责统一讲述，但不压过女主本人；每个系列先呈现她的风格与个性。
- 现实服务信息要清楚直白。价格、订阅条件、更新频率、退款/取消说明等不写成谜语。
- “军火走私船”“线人”“安全屋”均为虚构品牌隐喻；对应服务按真实功能说明，不让用户误解资源、交易或账号保障范围。

### 命名层级

中文显示名是现阶段的识别核心。X 与 Telegram 的用户名采用统一、可扩展的拉丁字母词根，具体 handle 先作为待核实项；实际注册前检查平台占用、长度规则及 Fragment 当时支持的交易类型。Fragment 仅作为 Telegram 收藏用户名等资产的后续采购渠道评估，不预设其支持购买 X 用户名。

后续形成社区矩阵时，可以把主品牌显示名升级为“教父工作室”或社区名称；「教父」保留为创始主理人/内容栏目 IP，原有频道负责向新矩阵导流。尽量保持用户名词根和导航入口稳定，减少迁移成本。

## 4. 内容宇宙

### 主号内容支柱

| 内容支柱 | 作用 | 呈现方式 |
|---|---|---|
| 主角档案 | 让观众记住不同女主 | 每位成年女主有艺名、风格关键词、系列编号与代表视觉 |
| 风格企划 | 展示女主之间的差异 | 根据本人气质设计服装、妆容、场景、镜头与叙事节奏 |
| 片场手记 | 建立「教父」的主理人视角 | 选题缘由、造型选择、拍摄准备、系列复盘 |
| 本周档案 | 将公开内容导向预览频道 | 简短说明编号、更新时间和导航入口 |

### 女主系列规则

- 每位出镜者都是成年女性；风格标签明确成年取向，不使用「萝莉」「嫩妹」、学生化或年龄含混的包装。
- 风格以本人特点为起点，可采用御姐、甜美、清冷、轻熟、复古、运动、职场等方向；具体造型由本人参与确认。
- 每个系列有独立编号和视觉锚点，不把所有人都套进「教父的同一种女主」模板。
- 初创阶段以主号集中推广为先，不设置客座/共创档期，不拆分资源运营多个平行主号。
- 后续开放合作时，再补充合作署名、内容授权、互推安排、收益分配与下架机制。

## 5. 用户路径与各入口分工

```text
X「教父」主号
  → 项目导航页
    → Telegram 公开预览「教父的战利品日记」
      → VIP 机器人「缄默法则通行证」
        → 会员频道「缄默法则之下」

资源交付：按需由「💎 军火走私船」承载
问询反馈：经「西西里线人」双向联系
入口变更：在「西西里安全屋」发布公告
```

| 入口 | 公开程度 | 运营职责 |
|---|---|---|
| X 主号 | 公开发现 | 建立主理人 IP、发布符合平台要求的预览内容 |
| 导航页 | 统一入口 | 汇总官方入口、减少主页链接频繁变更 |
| 预览频道 | 公开或可加入 | 预告、编号、更新时间；不承担付费交付 |
| VIP 机器人 | 用户主动触发 | 解释购买步骤、价格与状态；不以含糊文案替代条款 |
| 会员频道 | 会员访问 | 组织会员内容、更新公告与目录 |
| 资源机器人 | 按权限访问 | 存储或分发内容；不作为公开流量主入口 |
| 双向机器人 | 私聊交互 | 问题反馈与客服沟通；不主动群发拉人 |
| 防丢频道 | 备用锚点 | 仅发布经核实的官方入口与服务状态 |

## 8. 阶段路线

### 初创期：集中建立「教父」

- 推广一个主号，建立稳定的主理人叙事和女主系列档案。
- 先跑通 X → 导航页 → 公开预览的发现路径。
- 会员频道和机器人按真实功能逐步开放；尚未上线的入口保持隐藏或标明未开放。
- 不做客座共创，不宣称已有社区矩阵。

### 稳定期：会员档案与服务闭环

- 以清晰的更新目录、会员说明和客服入口建立持续服务。
- 复盘各女主系列的主页访问、关注转化、导航点击、预览加入和会员转化。
- 用数据调整系列投入，不因单条互动高低仓促更换品牌定位。

### 社区期：从个人主理人扩展为矩阵

- 主品牌可升级为工作室或社区，教父作为创始主理人 IP 延续。
- 再评估女主子系列、合作栏目、社区讨论和多账号矩阵；逐项建立运营与授权规则。
- 迁移时保留原用户名/链接可用性检查、公告窗口和旧入口导流。
