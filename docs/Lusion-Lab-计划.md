## 2. 计划原则

1. **不替换 `/`**：主站继续转化优先，Lab 只做隔离实验。
2. **只加一个场景元素**：地面/反射或半透明幕布，二选一；不堆粒子、不加音频。
3. **先性能后审美**：3D 如果不稳 55–60fps，直接回 2D。
4. **所有新东西必须可降级**：手机、reduced、static、WebGL off 都有 2D。
5. **不新增媒体/依赖**：纹理复用现有图片；three 已在项目里。
6. **先内部评审，不上生产 A/B**：Lab 是 dev route，没有真实流量，不假装做 CTR 实验。

## 4. 技术任务

### 4.1 性能与降级

- 测量：
  - 1440×1000 DPR1 / DPR2；
  - 1920×1080；
  - 390×844（应无 canvas）；
  - reduced / static / WebGL off。
- 指标：
  - rAF 5 秒采样 p50/p95；
  - `renderer.info`：draw calls、triangles、textures、geometries；
  - 页面 LCP/INP；
  - three 动态 chunk 大小；
  - 连续 3 分钟内存增长。
- 如果 DPR2 低于 55fps：
  - 优先 `setPixelRatio(Math.min(devicePixelRatio, 1.5))`；
  - 仍不行 → 只保留 2D。

### 4.2 Lab e2e

新增 `e2e/lusion-lab.spec.ts`：

1. 1440：`?experience=lusion` → 年龄门 → `data-lusion=true` → canvas 存在 → `.lg-backdrop.is-lusion` → 2D 背景隐藏。
2. 390：无 canvas，2D 背景可见。
3. reduced：无 canvas，2D 可见。
4. 静态按钮：场景卸载，2D 恢复。
5. 链接/主入口仍可点击；`/media` 请求不增加。
6. WebGL 创建失败：2D 保留。

### 4.3 一个空间元素（二选一）

**方案 A：地面 + 反射（推荐）**

- 在 y=-1.75 放一块深色地面；
- 用同一张纹理做一个低透明度镜像；
- 照片像“立在房间里”，而不是贴在屏幕上；
- 不加新图、不加新依赖。

**方案 B：半透明幕布**

- 照片后放一层很薄的渐变幕布/光幕；
- 指针移动时幕布轻微摆动；
- 更“放映室”，但纵深弱于 A。

**不做**：第二个 3D 物体、粒子增量、音频、滚动劫持、全屏 shader。

### 4.4 视觉评审

- 1440/390 各 0/2/5/10 秒截图；
- 10 秒录屏；
- 与当前 2D 光廊并排；
- 问 5 个人：
  1. 你看到的是“房间”还是“相框”？
  2. 10 秒后还记得什么？
  3. 会更想点 Telegram 吗？
  4. 手机上是否愿意等它加载？
