## 2. 运行与凭据

在 `web/` 依次执行：

```sh
npm ci
npm run setup
npm run media:import
npm run dev
```

公开页 `http://localhost:3000/`；后台 `http://localhost:3000/admin`。首次setup生成 `.env.local` 与 `var/local-admin.json`，两者权限均为0600，密钥／密码值不打印到终端、不写进交付报告。随机管理员没有公开默认密码。普通setup保留已有账号、配置和密钥；`npm run setup -- --reset-admin` 保留站点内容及用户名、生成新密码、提升认证版本并撤销全部旧管理会话。后台改密后以新密码为准。

运行环境必须提供精确的 `APP_ORIGIN`、显式数据库／媒体路径及两份独立密钥。开发只允许loopback HTTP；生产运行要求HTTPS，Cookie采用Secure、HttpOnly及Host前缀。SQLite和媒体放持久卷，首版为单实例。30天成年凭据、8小时管理会话及上传限额由实现常量约束；仅更改同名环境字段不会调整它们。

## 3. 当前本机内容

本机草稿已通过受控处理导入一张头像和五张照片，沿用既有顺序、说明及裁切焦点；设计源文件不进入公开静态目录。导入只更新草稿，今后首次成功导入会启用草稿照片条；已有媒体时工具保留现有配置和开关。当前本机已保存草稿为修订3，照片条开关已开启，包含五张照片；后续仍由后台管理配置。

正式已发布版本仍是初始bootstrap：名称与成年文案有值，五入口目标为空且停用、零媒体。当前本机根首页已按用户要求显式开启草稿预览，年龄确认后显示保存草稿中的头像和五张照片，照片条位于五入口之后。真实联系邮箱、中性离开目标与至少一个有效入口尚待填写，所以未执行运营发布。开发测试中使用隔离配置验证发布，不改变这些真实配置。

### 3.1 本机根首页预览开关

`.env.example` 默认 `LOCAL_DRAFT_PREVIEW=0`。本机现显式设为 `1`，仅当 `NODE_ENV=development`、origin为loopback HTTP且使用非Secure开发Cookie时生效。首页、年龄门中性metadata、图片和外跳解析共同采用 `local-draft-{revision}` 版本；后台未保存编辑不进入首页。成年确认与受控媒体鉴权继续生效。

生产、远程origin配置或HTTPS环境忽略此开关，读取正式发布快照。关闭时将 `.env.local` 中 `LOCAL_DRAFT_PREVIEW` 设回 `0`，重启开发服务，首页即恢复正式已发布内容。本次改动不更新正式发布指针，不补造真实目标、邮箱或离开地址；上线配置和正常发布校验继续保留。

新验收记录为 `docs/M3-本地首页照片条验证.json`；本次增量源码备份、差异和回退位于 `.requirements-history/20261029-local-home-gallery/`。原M3验证记录、源码包与回退保留为前一阶段历史交付，不覆盖。本次 `npm run check` 通过38／38项，`NEXT_DIST_DIR=.next-build npm run build` 退出0，`npm run test:e2e` 通过7／7项；隔离服务显式关闭草稿模式（`LOCAL_DRAFT_PREVIEW=0`），验证正常发布行为。真实本机首页另外以无管理员会话浏览器验证：`local-draft-3`，五张照片与头像均完整解码，确认前受控请求为0，390px没有横向溢出，刷新仍有五张照片。新记录保存本次证据，原33／7项记录继续保留历史身份。
