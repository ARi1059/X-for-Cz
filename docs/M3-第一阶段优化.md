# M3 · 第一阶段视觉与交互优化

更新：2026-11-02。对应清单 V01–V04；V01 高清背景沿用上一轮成果，本轮完成 V02 手机排版、V03 页脚触控、V04 按钮完整状态。第二阶段品牌、照片选中提示及入场节奏，第三阶段加载策略和真机性能检查保持待办。

## 实施结果

| 项目 | 优化前 | 第一阶段结果 |
|---|---|---|
| 390px 人像页左栏 | 156px | 约 172px，右缘留在左半屏 |
| 320px 人像页左栏 | 128px | 约 141px |
| 手机姓名 | 21–24px | 26px |
| 手机入口／状态 | 11–12px／8px | 13px／10px；短屏不缩字 |
| 手机装饰英文 | 最小约 4.5px | 隐藏过小装饰字，保留姓名层级 |
| 页脚点击区 | 最小约 38×28px | 本机实测最小 46×44px，目标互不重叠 |
| 手机页脚 | 9px 小字、紧凑两行 | 11px；两列、4px 行距；底部至少 14px 并读取安全区 |
| 短屏 | 为适配高度缩小字号 | 自然竖向滚动；320×568 内容约 603px 高 |
| 停用入口 | 第三入口仍有强调色 | 停用优先，弱化箭头和底色 |
| 导航等待 | 未定位到具体入口 | 当前入口“正在打开…”，其他可用入口暂缓操作 |
| 导航失败 | 全局提示 | 原入口下方显示原因与至少 44px 高重试操作 |

手机与平板背景改为按视口固定，保持原图比例及右侧锚点，避免短屏内容增长时人物被放大。原片、当前 1600×2000 展示图、五入口顺序和照片条均保留。普通页面仍读取已有配置，本轮未修改本机草稿或发布指针。

等待采用同步锁，在创建新标签前阻止同一轮连续点击。桌面新标签、修饰键、中键、内存确认、来源和版本参数沿用原流程。弹窗受阻会就近提示并允许重试；失败弹窗自动关闭。重试前焦点回到对应入口，方便键盘继续操作。

确认过期后回到确认页；版本更新时先保持等待，完成刷新后更新链接。去掉按版本整页重挂载，媒体与照片条仍按版本更新，同时保留手动静态浏览偏好和入口焦点。现有按压、焦点、系统减少动态及静态模式继续有效。

## 技能与实现范围

使用 `gsap-react` 与 `gsap-performance` 核对作用域、清理和动态偏好。新增状态使用 CSS 与 React 状态，没有增加持续动画。修改范围：

- `web/src/components/public-app.tsx`：等待、失败、防重与版本刷新。
- `web/src/components/public-view.tsx`、`light-gallery.tsx`：入口状态、播报、重试焦点。
- `web/src/components/navigation-state.ts`：共享状态类型。
- `web/src/components/light-gallery.css`、`web/src/app/noir-public.css`：手机布局、触控、停用／等待／失败呈现。
- `web/e2e/phase1-layout.spec.ts`、`phase1-navigation.spec.ts`：新增布局与导航回归。

## 验证记录

基线 `npm run check`：41 项通过。修改后类型、23 个接口契约及 41 项测试通过。生产构建通过；32 项浏览器场景全部得到通过结果：完整运行 31 项通过、1 项测试定位问题，修正后该项在干净测试缓存下定向复跑通过（6.1 秒），未重复运行其余 31 项。

实际本机预览截图包含九尺寸：1440×1000、1854×1018、850×1000、768×1000、549×844、390×844、320×844、375×568、320×568。全部无横向溢出，五入口位于左半屏，页脚点击区至少 44×44px 且无重叠；页面异常为 0，确认前媒体请求为 0，确认后头像与 1600×2000 背景正常解码。

新增浏览器测试使用独立临时数据库与媒体，访问 3103 端口；所有测试外跳被拦截，不修改 3000 本机配置。覆盖八尺寸逐项点击命中、弹层焦点恢复、快速重复操作、等待几何、失败重试、新标签、401 与真实 409 换版。另有 550px Telegram 等待／失败截图。该隔离服务使用初始测试照片，高清背景依据 3000 的九尺寸截图验证。

验证中保留了失败记录及修正过程：同工程两个开发服务出现热刷新循环，改用独立源码与依赖副本；401 的全局 alert 定位误匹配框架播报节点，已限定到产品提示；副本缺少契约读取的设计文案，补齐后检查通过；测试旧缓存导致重载，保留缓存后从干净测试缓存复跑通过。连续调整截图窗口尺寸曾出现底部合成残影，改为每个尺寸新建页面重新捕获；中等窄屏等待提示曾增加按钮高度，已为状态预留底部行，并通过全五入口几何检查。

本轮是 Chrome 桌面／手机尺寸模拟。真机帧率、耗电、高像素比、底部手势条和真实外部目标仍待验证；不将浏览器截图视作真机性能结论。
