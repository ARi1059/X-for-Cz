# M2 数据与接口约定

日期：2026-10-29  
版本：v1.0  
依据：`04-个人Link导航页-需求.md` v3.5、`设计开发计划文档.md` v1.3、M1 可编辑设计与 `design/公开文案配置-M1.json`。  
阶段边界：本轮建立配置契约、数据迁移、初始化与存储基础；本文 HTTP 路径是 M3 实现契约。接口定义验证、存储测试通过分别记录，均不表示浏览器页面、线上服务或部署已完成。

## 1. 技术与运行方式

| 层 | 首版决定 | 采用原因与边界 |
|---|---|---|
| 运行时 | Node.js 24 LTS，最低 24.12；TypeScript | 前后端使用统一类型；本机可使用已安装的更新 Node 版本运行基础验证 |
| M3 页面及接口 | Next.js App Router + React，同源 Node 服务 | 公开页、年龄门、管理员与 API 统一部署；受控内容使用动态响应，避免静态生成泄露 |
| 配置验证 | Zod 类型与导出的 JSON Schema | 管理端字段、服务端校验、配置示例使用同一来源；跨字段和发布约束由运行时补充 |
| 数据库 | SQLite，`node:sqlite`，WAL、外键、事务 | 单管理员与单实例首版；文件保存在持久卷，不放临时构建目录 |
| 图片 | 私有文件目录，服务端解码、重编码、生成衍生图 | 不放 Next.js `public/`；公开与管理员预览分别鉴权 |
| 托管形态 | 单 Node 实例的 VM 或容器，数据库与媒体挂持久卷 | 本轮不购买资源、不绑定域名；无持久卷的无状态函数环境不适用当前 SQLite 方案 |
| 测试 | 类型检查、配置契约验证、`node:test` 存储测试 | M3 补 HTTP 与浏览器流程，M4 执行需求的完整验收清单 |

生产用反向代理终止 HTTPS；应用只信任显式配置的 `APP_ORIGIN`。数据库和媒体目录不映射到公开静态路径。首版不做多实例共享 SQLite、自动伸缩、外部对象存储或消息队列；出现并发写入或多实例需求时再迁移数据库与媒体适配层。

## 3. 内容配置

`SiteConfig.schemaVersion` 固定为 `1`，`theme` 固定为 `ink-champagne`。主题由已确认的风格01「墨黑香槟」提供；后台仅维护内容、目标与图片，不开放颜色、CSS 或模板编辑。字符串为纯文本，渲染时转义；空白可选内容标准化为 `null`，不保存模板变量、`#` 或示例地址。

| 配置组 | 字段 | 初始值／规则 |
|---|---|---|
| `site` | `name`、`tagline`、`description`、`avatarMediaId` | 顾清棠；短发御姐，丝袜和高跟鞋；补充说明与头像引用为 `null` |
| `ageGate` | `title`、`notice`、`confirmLabel`、`exitLabel`、`exitUrl`、`exitNotice`、`resetLabel` | 沿用 M1 初始文案；`exitUrl=null` 时保留退出提示，不进入主页 |
| `links[]` | `id`、`label`、`description`、`url`、`position`、`visible`、`enabled`、`emphasized` | 五种固定 ID 各一条；地址 `null`，全部禁用，可见；`tg_preview` 为唯一轻强调 |
| `gallery` | `enabled`、`title`、`photos[]` | 初始照片为空；有照片也始终位于完整入口列表之后 |
| `gallery.photos[]` | `id`、`mediaId`、`alt`、`caption`、`position`、`visible`、`focalPoint{x,y}` | 稳定照片 ID；独立媒体引用；焦点坐标 0–1；可选说明为空 |
| `info` | `title`、`body`、`faq[{id,question,answer}]` | 默认空与空数组，公开隐藏 |
| `footer` | `notice`、`contactEmail`、`removalNotice`、`updateText` | 声明沿用 M1，其余真实信息未提供时为空 |
| `meta` | `title`、`description`、`shareMediaId` | 中性标题与描述；分享图引用初始为空；后续仅引用明确审核中性的 `public_share` 素材，不由头像自动生成 |
| `states` | `unavailable`、`loading`、`empty`、`error` | 暂未开放；加载中…；内容暂未开放；加载失败，请稍后重试。 |

固定链接 ID 为 `x_profile`、`tg_personal`、`tg_preview`、`onlyfans`、`membership`。Telegram 个人账号和会员 Bot 使用不同条目。位置为 1–5 的唯一排列，强调条目至多一个。照片条最多 12 张，排序不重复；零张时整区隐藏，一张时隐藏多余分页与切换。名称、标签最多 24 个字素，短简介最多 90 个字素；所有字段完整限额由配置类型源统一管理。JSON Schema 的字符串长度与用户感知字素不完全相同，运行时仍执行字素计数。

现有六张照片继续作为设计素材，保留文件与裁切来源；初始化工具不把设计目录本机路径写入运行时公开配置。M3 由管理员受控导入，完成真实格式检测、去 EXIF 与衍生图生成后取得 `mediaId`，再配置草稿与发布。

### 3.1 草稿与发布检查分开

结构合法的未完成草稿可保存；例如目标地址、离开目标和邮箱为空，保持禁用状态，编辑不丢失。正常发布另检查：

1. 名称、年龄标题、提示和两个按钮完整，保留“仅限成年人”及“本人已年满18岁”的自主声明语义；不宣称已完成真实年龄核验。确认按钮采用“我已年满 18 岁”或同义正向模板，可追加“继续／进入／确认”；仅包含数字18或否定成年状态的文字不通过发布。
2. 离开目标为有效、中性的 HTTPS 外部地址；联系邮箱有有效格式。中性语义由管理员评审，格式校验不宣称自动识别全部页面内容。
3. 至少一个可见、启用、目标有效的入口；其余入口允许禁用或隐藏。URL 拒绝模板、示例域名、脚本协议、凭据段及本站管理地址；外跳不接受访客指定的任意目标。
4. 所引用媒体均存在且 `ready`，包括头像、照片与分享配置；头像和照片只使用 `controlled` 资产，中性分享图只使用明确审核的 `public_share` 资产。照片替代文本、排序和焦点有效；隐藏内容仍不能引用失效媒体。
5. 发布请求的 `expectedRevision` 等于当前草稿 revision；写入期间再次核对媒体状态与引用。

`parseSiteConfig` 执行结构与基础关系检查，`validateForPublish` 返回 `{path, code, message}[]`。`siteOrigin`、`readyMediaIds` 和 `publicShareMediaIds` 由服务端传入；HTTP 请求不能自行声称媒体已就绪或关闭上线检查。

### 3.2 初始空配置

首次 CLI 初始化只写一次 `bootstrap` 快照：品牌文案有值、五个入口全部禁用、真实地址和邮箱为空、媒体引用为空。它让年龄门及空配置状态在 M3 有明确起点，不代表已具备运营配置。初始化检测到已有草稿或发布数据时不覆盖它们。正常 HTTP 发布没有 `skipValidation`、`bootstrap` 或等价绕过参数。

M1 原始文案 JSON 保留设计基线身份；M2 初始化配置是一次性映射。服务运行后，以数据库草稿与已发布快照为准，不在重启时重新读取种子覆盖管理员编辑。

## 4. 数据模型与事务

| 表／实体 | 关键内容 | 约束 |
|---|---|---|
| 迁移记录 | 迁移文件名、SHA-256、执行时间 | 重复执行幂等；旧迁移哈希变化即停止 |
| `site_draft` | 单条配置 JSON、`revision`、更新时间 | singleton；每次成功保存 revision + 1 |
| `published_versions` | 不可变配置 JSON、SHA-256、源 revision、创建者、时间、bootstrap 标志 | 已发布快照禁止更新和删除；外部 `versionId=String(id)` |
| `published_pointer` | 当前版本 ID | singleton；只在完整发布事务中切换 |
| `media_assets` | 随机媒体 ID、私有存储 key、MIME、字节、尺寸、SHA-256、状态、`purpose` | 状态 `pending/ready/failed`；用途 `controlled/public_share`，默认受控；存储 key 与路径不公开 |
| `draft_media_refs` | 当前草稿 → 媒体 | 外键阻止删除草稿引用的资源 |
| `published_media_refs` | 保留发布版本 → 媒体 | 不可变；外键阻止删除任何保留快照引用的资源 |
| `administrators` | 唯一管理员、密码哈希、`auth_version` | 只允许 ID=1；无默认账号密码 |
| `admin_sessions` | token hash、CSRF hash、auth version、创建和到期时间 | 仅存摘要；过期清理，改密后旧版本失效 |
| `age_revocations` | 当前撤销凭据的 token hash、到期时间 | 不保存身份；到原凭据期限后删除 |
| `daily_statistics` | UTC 日期、来源枚举、事件枚举、入口枚举、计数 | 非点击事件无入口；不存原始 IP、访客账号或请求明细 |
| `audit_log` | 动作枚举、管理员 ID、revision／version／media ID、时间 | 结构化白名单，不写密码、token、完整配置与任意请求体 |

正常发布顺序为：`BEGIN IMMEDIATE → 比较 revision → 验证完整配置和媒体 → 插入版本及媒体引用 → 切换当前指针 → 记录审计 → COMMIT`。出现校验、外键、磁盘或写入错误时 `ROLLBACK`，原发布指针与公开内容不变。草稿保存也使用 revision 比较；两个管理标签页同时保存时，后写者获得 409，由界面保留输入并提供重新加载。

媒体删除先检查草稿和所有保留发布版本的引用。只从草稿移除照片不删除当前公开图片。首版保留历史版本，不提供自动历史清理；后续若新增回收功能，应通过显式版本保留策略和迁移实现，避免直接删除仍被历史版本引用的文件。

公开请求先读取当前版本指针与完整快照。返回主页包含 `versionId`；外跳与媒体请求携带该版本，服务器发现已经切换则返回 409，界面重新加载主页。这样旧页面不会混用新版本目标或新的图片。页面中已经绘制的内容无需实时更新；下一次请求或刷新读取新发布版本。

## 5. 年龄状态与管理员权限

### 5.1 成年自主声明

`GET /api/gate` 仅返回名称、中性标题和描述、年龄门文字、离开目标、年龄状态及短期 CSRF 挑战。它不含短简介、五入口、受控照片 ID、受控图片 URL、管理员信息或草稿。中性 metadata 可包含已明确审核并发布的 `public_share` 分享图 ID，初始为空；公开 `/share/{mediaId}?version=...` 只读取当前版本中该资产，绝不把普通头像或照片自动公开。页面渲染和 Next.js 预取都遵守此边界；SSR 与页面源码也不能嵌入已下载后隐藏的受控内容。

确认请求为同源 JSON，要求 `adult=true`、`Origin` 匹配及 `X-CSRF-Token` 有效。公开 CSRF 挑战为短期签名值，只经同源读取获得；不承担成年资格。M3 固定挑战有效期与校验实现，任何缺失或 `Origin:null` 请求均失败。

Cookie 模式签发 `__Host-age`，设置 `Secure; HttpOnly; SameSite=Lax; Path=/`，不设置 Domain。签名负载含用途、随机凭据标识、首次签发与到期时间；使用独立 HMAC 密钥与恒定时间比较。`expiresAt=issuedAt+2592000秒`，重访和已有有效凭据的重复确认不续期。

Cookie／存储受限时选择 `storage=memory`，服务端返回有同样签名与期限的 Bearer token。前端仅在当前标签页内存保存，不写 URL、`localStorage`、`sessionStorage` 或日志；页面卸载、刷新后重新确认，不循环跳转。

内存 token 的三条访问路径：

- 主页：同源 `fetch('/api/site')` 带 `Authorization: Bearer ...`。
- 图片：同源授权 fetch → Blob URL → 图片元素；重置和卸载时撤销 Blob URL，不把 token 拼入图片地址。
- 外跳：调用 `POST /api/links/{linkId}/resolve`，服务端按当前发布版本和固定 ID 校验并计数，返回目标后进行浏览器导航。原生导航无法携带 Bearer 头，因此不使用跨域 fetch 跟随 302 读取 Location。

`POST /api/age/reset` 清 Cookie、撤销当前凭据摘要至原到期时间，客户端清内存 token、受控页面与 Blob URL。撤销表只保存哈希与到期时间，不建立访客身份表；清除单个访问状态不影响其他访客。后台定期清理到期撤销记录。

### 5.2 管理员会话

管理员会话与成年凭据分离，持有成年 Cookie 不获得后台权限。登录使用严格同源 Origin 与 JSON；后续写操作额外核对当前管理会话 CSRF token。`__Host-admin` 为加密随机 opaque token，库中仅存 SHA-256 摘要，Cookie 为 Secure、HttpOnly、SameSite=Strict、Path=/。

管理会话默认固定 8 小时，不滚动续期。密码使用 Node `crypto.scrypt`，每个密码独立随机盐并保存算法参数；实际参数及资源限制由 M3 初始化工具统一管理。修改密码或部署侧重置增加 `auth_version` 并撤销旧会话，要求重新登录。没有公开默认账号、密码或注册接口；初始化凭据通过交互式输入或受保护秘密来源提供，不放入命令参数、示例配置与仓库。

登录按站点和短期匿名限流键限速，错误不区分账号是否存在；需要 IP 派生限流键时只保留带日轮换密钥的摘要及短 TTL，不写入统计或审计。生产访问日志也需要脱敏并设置保留期。鉴权、CSRF、会话到期与限流的真实 HTTP 行为属于 M3／M4 验证。

## 6. HTTP 契约

完整可机器读取定义见 `web/contracts/openapi.json`，共 21 条路径、23 个操作。版本标识通过字符串传输，草稿 revision 为正整数；响应时间为 ISO 8601 UTC。查询参数不接受任意重定向地址。

| 方法与路径 | 凭据 | 主要请求／返回 |
|---|---|---|
| `GET /api/gate` | 无 | Gate 投影、中性 metadata、CSRF 挑战 |
| `POST /api/events/gate-view` | 同源＋公开 CSRF | `{source}`；204，仅计实际显示 |
| `POST /api/age/confirm` | 同源＋公开 CSRF | `{adult:true, storage, source}`；固定期限 AgeGrant |
| `POST /api/age/reset` | 成年 Cookie 或 Bearer＋CSRF | `{}`；204，撤销当前凭据 |
| `POST /api/age/leave` | 同源＋公开 CSRF | `{source}`；`{exitUrl,notice}`，空目标停留提示 |
| `GET /api/site` | 成年 Cookie 或 Bearer | 当前公开投影与 versionId |
| `GET /go/{linkId}?version=...&from=...` | 成年 Cookie | 302 到已发布目标；服务端计数 |
| `POST /api/links/{linkId}/resolve` | 成年 Cookie 或 Bearer＋CSRF | `{versionId,source}`；`{versionId,url}` |
| `GET /media/{mediaId}?version=...&variant=...` | 成年 Cookie 或 Bearer | 当前版本引用且 ready 的衍生图片 |
| `GET /share/{mediaId}?version=...` | 无 | 当前发布中明确审核中性的 `public_share` 图片；初始为空 |
| `POST /api/admin/login` | 同源 Origin | `{username,password}`；管理 cookie 和会话信息 |
| `GET /api/admin/session` | 管理 Cookie | 用户名、固定到期时间、CSRF token |
| `POST /api/admin/logout` | 管理 Cookie＋CSRF | `{}`；204，当前会话撤销 |
| `PUT /api/admin/password` | 管理 Cookie＋CSRF | 当前与新密码；204，旧管理会话全部失效 |
| `GET /api/admin/draft` | 管理 Cookie | `{revision,updatedAt,config}` |
| `PUT /api/admin/draft` | 管理 Cookie＋CSRF | `{expectedRevision,config}`；新 revision |
| `GET /api/admin/preview` | 管理 Cookie | 草稿、revision、发布问题列表，未发布 |
| `POST /api/admin/publish` | 管理 Cookie＋CSRF | `{expectedRevision}`；201 与已发布版本 |
| `GET /api/admin/media` | 管理 Cookie | 分页媒体清单及引用，不含磁盘路径 |
| `POST /api/admin/media` | 管理 Cookie＋CSRF | multipart `file/purpose/neutralConfirmed`；处理成功后返回 ready 媒体 |
| `DELETE /api/admin/media/{mediaId}` | 管理 Cookie＋CSRF | 无引用才删除；仍被引用返回409 |
| `GET /api/admin/media/{mediaId}/content` | 管理 Cookie | 草稿预览媒体，独立于公开成年凭据 |
| `GET /api/admin/stats?from=...&to=...` | 管理 Cookie | UTC闭区间，最多90天的聚合计数 |

除图片流和 302 外，正常 JSON 的形状由各操作定义。错误统一为 `{error:{code,message,requestId,fields?}}`；`fields` 中每项为 `{path,code,message}`。401 为凭据缺失／到期，403 为同源／CSRF／权限不符，409 为版本或引用冲突，422 为字段／上线校验失败，429 带 `Retry-After`。500 不返回 SQL、路径、堆栈、凭据或未发布配置。

所有配置、管理、鉴权和受控媒体响应设置 `Cache-Control: private, no-store`；M3 不让 CDN、Next.js 静态缓存或 Service Worker 缓存受控内容。图片额外设置 `X-Content-Type-Options: nosniff`。管理预览 URL 与原始 SiteConfig 不写进公共响应。

## 7. 图片处理、统计与审计

上传默认限制为单张 10 MiB、2400 万像素、最长边 6000px、媒体总量 500 MiB。只接受真实 JPEG、PNG、WebP；检测文件头并完整解码，扩展名和请求 MIME 不能作为唯一依据。处理失败不标 ready，不发布源文件；清理本次临时文件，其他草稿和公开图片保持。生成符合 M1 的缩略图与展示图，去 EXIF 和位置数据，路径只由服务端媒体 ID 与存储层映射。上传必须选择 `controlled` 或 `public_share`，后者要求管理员明确确认内容中性（`neutralConfirmed=true`），否则拒绝；受控上传为 false。此确认不宣称自动内容审核，资产用途不得由公共请求更改。

统计以 UTC 日聚合，来源固定 `profile/pin/weekly/other`；未知来源归 `other`。事件为 `gate_view/adult_confirm/leave/link_click`；前三类的 link ID 为空，点击类必须为固定五 ID 之一。年龄门展示由显式 POST 计数，确认、离开和有效外跳由对应服务端动作计数。公开接口不允许客户端提交任意 `link_click`。单次外跳只选择 go 或 resolve 之一；仍属于请求点击量，不是去重人数、频道加入或成交。

管理员审计记录动作和结构化实体 ID，不接收任意 JSON 元数据。不记录姓名、生日、访客账号、明文 IP、Cookie、Bearer、密码或完整配置；托管访问日志与应用汇总分离。

## 8. 初始化、迁移与恢复

1. 准备独立本地验证数据库路径，运行迁移；连接启用 WAL、外键和繁忙等待。
2. 校验 `initial-site.json` 与配置 Schema，一次性写入草稿和零媒体 bootstrap 快照；重复执行不改变现有内容。
3. 检查当前 revision、versionId 与待配置字段。管理员账号由单独受控初始化流程创建，种子不包含凭据。
4. M3 完成上传后，把媒体 ID、真实 URL 与邮箱填入草稿；先预览，再通过上线校验发布。
5. 迁移前备份数据库；运行中用 SQLite online backup 或停止写入后的完整一致副本，不能只复制活跃 `.sqlite` 主文件而忽略 WAL。
6. 备份包包含一致数据库、所有被保留版本引用的媒体、媒体哈希清单、应用与迁移版本；签名密钥单独受控保存。恢复到独立目录验证迁移校验和、外键、当前指针、配置哈希及媒体哈希后，再安排切换。

M2 的回退演练针对本轮源文件与测试数据库；线上备份轮换、真实媒体恢复、密钥轮换和运维告警在 M4／M5 验证。草稿、已发布快照与媒体不会由源代码回退脚本自动覆盖。

## 9. M2 完成条件与 M3 衔接

M2 验收以实际脚本与测试输出为准：配置与 OpenAPI 引用可解析；五入口／空值／语义／媒体发布检查有效；迁移和重复初始化幂等；并发草稿的 revision 冲突被拒绝；失败发布保留旧指针；已发布版本不可变；媒体引用保护有效；关闭重开数据库后状态仍存在。

M3 从本契约实现同源 HTTP 路由、管理员初始化与登录、年龄凭据、受控媒体处理、公开页面和后台编辑。开发顺序优先贯通“初始化 → 年龄确认 → 读取当前版本 → 管理编辑 → 预览 → 发布 → 公开更新”，再覆盖失败与边界状态。浏览器中的固定30天、不续期、存储受限、键盘、媒体缓存与真实恢复仍需运行验收，不能用契约文件代替结果。
