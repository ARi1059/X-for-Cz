### 2.2 测试基线

- `npm run check`：类型检查、23 个 OpenAPI 操作、41 项单元/契约测试全部通过（2026-11-02 实测）。
- `npm run test:e2e`：26 个顶层 test 声明（部分循环展开），使用独立 3103 服务与 fixture 数据库。
- 现有测试对以下选择器/行为有硬依赖，改动时必须同步更新：
  - `.lg-platform` 五个入口、`.lg-link-shell`、`.lg-link-end small`、`.is-emphasized`。
  - `.link-feedback`、`role="alert"`、`重试打开…` 按钮、`aria-describedby`。

- 发布版本不可变；Phase 4.6 若重新导入人像，必须保留旧媒体与旧版本，不能删除。
- 公共页功能文字 ≥ 10px；触控目标 ≥ 44×44px；不依赖颜色单独传达状态。

## 7. 顺序、依赖与估算

| 阶段 | 依赖 | 估算 | 里程碑 |
|---|---|---|---|
| Phase 0 | 决策 D1–D7 | 0.5 人日 | M0 基线 |
| Phase 1 | M0 | 2–3 人日 | M1 light-gallery 结构签收 |
| Phase 2 | M1 | 1–2 人日 | M2 反馈签收 |
| Phase 3 | M2 | 2–3 人日 | M3 动效签收 |
| Phase 1b | M1（可与 Phase 2 并行） | 1–2 人日 | M4 首页/确认页品牌 |
| Phase 4 | M3 | 1–2 人日（+1–2 条件媒体） | M5 响应式/资源签收 |
| Phase 5 | M5 | 0.5–1 人日 | M6 照片条（可选） |
| 最终回归 | 全部 | 1–2 人日 | 可交付 |

**关键路径：** Phase 0 → 1 → 2 → 3 → 4 → 回归。Phase 1b 可与 Phase 2/3 并行，但必须单独提交、单独回滚。

**为什么这个顺序：**

1. 结构决定 DOM 与测试选择器，先改结构，后面的动效与反馈才不会反复改。
2. 反馈（错误/等待）依赖最终行高与行内布局，放在动效前。
3. 入场/扫光/弹层依赖最终 DOM 与状态，放在反馈后。
4. 响应式与媒体放在最后，避免在视觉未定时反复调图片尺寸。
5. 首页/确认页是生产可见，等预览签收后单独做。

## 8. 风险与回滚

| 风险 | 触发 | 缓解 | 回滚 |
|---|---|---|---|
| R1 测试大量失效 | 行高/类名/扫光终点变化 | 冻结 `.lg-platform`、`.is-emphasized`、`.link-feedback`；只允许扫光终点变更 | 同 PR 更新测试；保留旧测试快照 |
| R2 入场闪烁 | 首帧显示终态再隐藏 | `useGSAP` layout effect；先 `set` 后 `from`；慢 CPU + reduced 测试；必要时只做 y/opacity .7→1 | 关闭入场，保留静态 |
| R3 错误行裁切/溢出 | 长文案 + 44px 重试 | 单行省略 + 完整 aria 文本；200% 缩放；必要时加“详情” | 改回锚定浮层（不推布局） |
| R4 弹层关闭/焦点异常 | CSS `allow-discrete` 或 Safari | 先做打开动画，关闭保持瞬时；焦点返回必须通过 | 去掉关闭动画 |
| R5 金色过灰 | 去金后层级不足 | 姓名 + 主入口保留暖金；灰度检查；A/B 截图 | 恢复一个次级金线，不加回图标金 |
| R6 320 页脚单行过挤 | 四操作 + 11px | 44px 目标、gap 8、必要时 10px 字号/两行回落 | 回退两行，保留字号 |
| R7 媒体大图重新导入 | D6-B | 备份 SQLite/media；保留旧媒体；新版本发布；对比构图 | 恢复 display 上限/旧草稿引用并重新发布 |
| R8 LQIP 破坏请求断言 | 加第三张图/请求 | 默认不做；内联 LQIP；不改 2 图断言 | 去掉 LQIP，回到渐变 |
| R9 首页/确认页生产回归 | Phase 1b/3b | 单独提交、单独部署、24h 观察；保留旧截图 | revert 单个提交 |
| R10 减少动态回归 | 新动画未受 `data-motion` 控制 | 每个动画都写 reduced/static 终态；e2e | 关闭对应动画 |
| R11 e2e 动画 flake | 几何测试跑在动画中 | 几何测试用 `reducedMotion: 'reduce'`；轮询终态；不写精确毫秒断言 | 标记 flake 并重跑 |
| R12 颗粒/模糊性能 | 大图 + overlay + backdrop | 2–3% 静态、无持续动画；低端机截图/帧时间 | 去掉颗粒/模糊 |
