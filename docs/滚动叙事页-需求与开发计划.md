# Story Lab 公开页：需求与交互

日期：2026-11-04 起稿，2026-11-06 更新为唯一公开页  
状态：已实现，成为 `/` 的公开页；不再有 `?experience=` 变体。

品牌更新：2026-11-10；名称、主理人、七个频道/机器人角色遵循 `IP宇宙设定-v1.md`。

## 1. 一句话

年龄确认后进入一页五段式滚动叙事：背景随滚动在人像之间交叉淡入，左侧固定面板依次切换「与我相遇 / 教父主理 / 预告频道 / 会员有什么 / 购买方式」，`tg_personal` 入口显示为「西西里安全屋」，与个人账号、双向联系分开配置。

## 2. 页面结构

| 章节 | 内容 |
|---|---|
| 01 与我相遇 | 头像、姓名、短简介、五个导航入口、防丢说明 |
| 02 教父主理 | 简介文案、X / Telegram 数据（可接真实 API，未配置时为示例数据并标注）、关注入口 |
| 03 预告频道 | 最新 2–3 条 X 帖子预览（只拉取链接与预览图，不在服务器保存原片）、进入频道 |
| 04 会员有什么 | 四档会员（单月 / 季度 / 年费 / 永久）、权益列表、价格以 Bot 实时报价为准 |
| 05 购买方式 | 五步购买流程、完整教程弹窗、USDT 风险提示、打开 Telegram Bot |

桌面：五张背景图按滚动进度交叉淡入；左侧面板切段时更新 `aria-hidden`/`inert` 与章节导航；底部中央为下拉提示，末段自动隐藏。手机（<960px）：改为普通纵向文档流，每段「全屏人像 + 内容」，下拉提示滚动到下一段。

## 3. 交互与可访问性

- 年龄门先于一切内容：确认前不请求头像、简介、入口或受控媒体；确认状态固定 30 天（或仅本次访问）。
- 入口点击经 `/go/[linkId]` 解析：桌面新标签页、手机当前页；失败在原位显示重试，不移动五行动线。
- 键盘：章节导航按钮、下拉提示、弹窗均可聚焦；`prefers-reduced-motion` 时禁用背景交叉淡入与入场动画，并提供「静态浏览」开关。
- 桌面自定义光标只在 hover + fine pointer + 非减少动效时挂载。
- 弹窗使用原生 `<dialog>`，支持 Esc 关闭与焦点返回。

## 4. 视觉

墨黑底 + 香槟金；标题宋体，正文思源黑/苹方；细线分隔、编号化章节。规范见 [../design/Story-Lab-视觉规范.md](../design/Story-Lab-视觉规范.md)。

## 5. 数据来源

| 数据 | 来源 | 未配置时 |
|---|---|---|
| 站点文案、入口、头像、分享信息 | 草稿 / 发布版本（SQLite） | 初始配置 |
| X 粉丝数与最新帖 | `X_BEARER_TOKEN` + `X_USERNAME` | 示例数据，标注“示例数据” |
| Telegram 频道人数 | `TELEGRAM_BOT_TOKEN` + 频道 id | 示例数据 |
| 会员档位与教程 | `story-content.ts` 内的固定文案 | — |

`/api/lab/story` 缓存 5 分钟，请求超时 6 秒，失败时回退示例数据。

## 6. 不做的范围

- 站内收款、订单或支付信息存储（全部在 Telegram Bot 内完成）。
- 服务端保存 X 原片、自动搬运媒体。
- 真实价格承诺：页面只展示档位与周期，价格以 Bot 报价为准。
- 多语言版本、A/B 实验入口。

## 7. 验收

- 首次访问只见年龄门，确认后才加载 Story Lab；重置年龄后回到门。
- 桌面滚动五段背景依次交接、面板内容同步；手机五段可正常滚动且无横向溢出。
- 五个入口状态（可用 / 未开放 / 错误重试）正确；外跳带来源统计。
- 减少动效与静态浏览模式下内容完整可见。
- 后台保存草稿后，本机首页（`LOCAL_DRAFT_PREVIEW=1`）刷新即可看到；全屏预览不改变发布指针。
