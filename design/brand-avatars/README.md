# 频道与个人头像

多组独立的圆形头像母版，均为 512×512 SVG，无外部字体或图片依赖，适合继续编辑及导出为 PNG。

机器人头像：

| 文件 | 用途 | 主视觉 |
|---|---|---|
| `arms-runner-ship.svg` | 资源存储机器人「军火走私船」 | 午夜蓝海面、货船与封存货箱 |
| `silent-code-pass.svg` | VIP 付费机器人「缄默法则通行证」 | 酒红会员凭证、钥匙孔与金钥匙造型 |
| `sicily-informant.svg` | 双向机器人「西西里线人」 | 墨绿双气泡与往返箭头 |

| 文件 | 用途 | 主视觉 |
|---|---|---|
| `godfather-personal.svg` | 个人账号「教父」 | 黑金徽章、成年男性西装侧影、红玫瑰 |
| `silent-code-members.svg` | 会员频道「缄默法则之下」 | 金色法则之门、封缄 |
| `trophy-diary-preview.svg` | 预览频道「教父的战利品日记」 | 酒红日记本、星形印记、书签 |
| `sicily-safehouse.svg` | 防丢频道「西西里安全屋」 | 橄榄绿石屋、拱门、橄榄枝 |

头像本体不放频道名称，避免缩成平台头像后文字糊成一团；频道显示名与头像符号分工识别。四张共用双圈徽章边框，但主色分别为黑金、暗红、酒红与橄榄绿。

## 教父 IP 使用位置

SVG 母版保存在本目录，PNG 原件位于项目根目录，站点副本位于 `web/public/brand/`。个人号主品牌使用教父徽章，其他六枚分别用于对应频道与机器人；女主作品照片不作为主品牌身份。
