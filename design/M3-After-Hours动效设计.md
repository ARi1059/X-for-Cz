# After Hours · 墨黑香槟私人秀场

更新日期：2026-10-29  
版本：1.0  
范围：M3 公开页面视觉增量。依据本轮用户“极具视觉冲击的动效网页”请求，更新主页及年龄确认页的呈现；M1 静态稿保留为历史基线。

## 设计方向

以顾清棠的短发轮廓、冷艳气质和礼服造型为中心，使用墨黑、香槟金和暖白构成舞台感。视觉重点是侧光、轮廓、金属细线与大字号衬线字；现有用户照片保持原顺序和色彩，成为页面中最鲜明的颜色。

页面仍按“头像与名称／简介 → 五个纵向入口 → 横向照片 → 辅助信息与页脚”展开。背景中的 `After hours.`、侧栏小字与光环是装饰，入口与正文保持独立、清晰的阅读顺序。

## 视觉与动效

| 部位 | 当前设计 |
|---|---|
| 年龄确认页 | 私人邀请函式布局，衬线名称与 `18+`，香槟金确认按钮；确认前只展示中性信息及抽象光效 |
| 身份区 | 双层细线头像框、衬线中文名称、小字简介和短金线，分段依次入场 |
| 五入口 | 统一编号、线性图标、金属质感面板；保留主要入口描边强调，可用入口具有掠光与箭头反馈 |
| 背景 | 墨黑渐变、两侧舞台光、椭圆轮廓、缓慢光斑与桌面聚光跟随 |
| 照片 | 原五图放大为 4:5 造型展，显示编号和说明，进入视口时浮现；精细指针设备支持轻微倾斜 |
| 页脚 | 衬线签名式短句、细分隔线、原有年龄提示和重新确认操作 |

身份与入口区域最大宽度为 540px；桌面照片区域最大宽度为 980px，可同时展示五张照片。手机保留单列入口，照片以部分下一张露出的横向布局提示滑动。后台草稿预览复用同一组件，并将背景与动效限制在预览容器内。

动效由 `gsap` 与 `@gsap/react` 管理，图标使用 `lucide-react`。入场与悬停以位移、透明度和轻微旋转为主；不接管页面滚动，不替换系统指针。字号和布局细节以当前代码为准。

## 交互与静态模式

- 顶栏“暂停动效”停止舞台循环及跟随效果，并恢复内容的完整可见状态；“启用动效”可重新开启。
- 系统设置 `prefers-reduced-motion: reduce` 时自动进入静态模式，禁用主动开启动效，照片翻页使用即时滚动。
- 照片保留左右按钮、触摸横滑、键盘左右键、当前位置计数和边界禁用状态。
- 装饰层不拦截点击，焦点轮廓与按钮触控面积保留；页面切换和预览关闭时清理动画、观察器与事件监听。

## 内容与发布边界

这次修改只调整公开呈现及其共享预览，不修改内容配置、照片文件、草稿 revision 或正式发布指针。正常页面访问仍按既有逻辑记录汇总事件。名称、简介、五入口标签、照片与功能文案继续读取当前配置；新增英文短句属于固定视觉装饰，不新增后台主题编辑功能。

年龄确认后才挂载照片组件，并继续通过受控媒体接口加载。放大的照片使用既有 `display` 衍生图，保留版本、凭据、裁切焦点、加载失败及访问过期处理。后台预览沿用管理员鉴权。

当前本机首页仍使用已显式开启的 `LOCAL_DRAFT_PREVIEW=1`，显示保存草稿 `local-draft-3`。五个真实目标尚未填写，入口维持停用；正式已发布快照仍是初始空配置。视觉更新不等于内容发布或外部部署。
