- 唯一主题为风格01「墨黑香槟」：墨黑底、象牙字、少量香槟色强调。风格02、03及既有静态图保留供历史追溯。
- 名称字段保留 `SITE_NAME`，初始显示为「顾清棠」。名称仍为暂定；“暂定”只出现在文档与管理说明，公开名称仅显示「顾清棠」。成年确认页、主页与后台预览读取同一配置源。
- 历史视觉来源为 `design-references/2026-10-29-Linktree-御姐风/01-墨黑香槟-v4.png`；当前文字以 Figma M1 稿、`design/exports/M1/` 及 `design/公开文案配置-M1.json` 为准。正式稿使用可编辑文字、自动布局及组件实例，静态图像素值不直接充当 CSS 尺寸。

- 短简介沿用共用系列承诺“短发御姐，丝袜和高跟鞋”；五入口、成年确认和页脚使用内容基线中的文字。初始真实目标仍为空，五入口禁用并显示“暂未开放”。已配置状态仅用于组件样式说明，不代表真实目标已填写或上线。

## 3. 字体与文案尺寸

中文优先使用 `Noto Sans SC`；实现时回退顺序为 `Noto Sans SC, PingFang SC, Microsoft YaHei, system-ui, sans-serif`。设计稿须记录实际使用字体；字体替代须重新检查换行。系统优先意味着无需为首屏强制阻塞下载字体。

| 样式 | 字号／行高 | 字重 | 使用位置 |
|---|---|---|---|
| `title` | `28 / 40px` | Medium 500 | 公开名称、页面主标题 |
| `heading` | `20 / 30px` | Medium 500 | 管理分区与次级标题 |
| `label` | `14 / 22px` | Medium 500 | 公开入口、主要操作与字段标签 |
| `body` | `14 / 22px` | Regular 400 | 简介、字段值、说明 |
| `caption` | `12 / 18px` | Regular 400 | 页脚、字段帮助、状态说明 |

公开页短简介显示 1–3 行；名称换行保持居中，不使用横向滚动文字。入口标签默认一行；长标签允许两行并统一增高该列表中的按钮，维持统一层级。完整标签可读，省略号不作为唯一的信息承载方式。

建议编辑长度用于 M1 排版与后续字段校验讨论：名称 24 个字素、简介 90 个字素、入口标签 24 个字素、入口辅助说明 40 个字素。字素按用户感知字符计数；上限落地前由 M2 字段约定统一确认。超长测试同时覆盖中文、英文、emoji 与无空格 URL。

## 4. 响应式布局与图片

| 画面 | 参考尺寸 | 内容区 |
|---|---|---|
| 手机窄屏 | `360 × 940px` | 两侧 `20px`，可用宽度 `320px`；可纵向滚动 |
| 手机常见屏 | `390 × 940px` | 两侧 `20px`，可用宽度 `350px`；可纵向滚动 |
| 桌面公开页 | `1440 × 1100px` | 窄列居中，最大宽度 `600px` |
| 桌面后台 | `1440px` 宽，内容可纵向延伸 | 工作区最大约 `1200px`，按表单与预览需要排布 |
| 手机后台 | `390px` 宽，并检查 `360px` | 分区导航、表单、预览入口上下排列 |

公开内容容器宽度取扣除水平内边距后的可用宽度与 600px 中较小者。头像为 80px 圆形；链接默认高 56px、间隔 12px、圆角 28px。头像、名称、简介和列表之间的其余间距读取对应画面的自动布局，不另设一套与画面分离的标注。

五入口保持连续列表；940px 是设计画板高度，并非对真实设备首屏高度的承诺。三行简介或超长标签按内容自然增高，页面纵向滚动；优先保证文字完整、触控尺寸和模块顺序，不裁切或覆盖入口以强行塞入一屏。页面主体在 360px 宽度下没有横向溢出。

照片条位于完整链接列表之后。缩略图为 80×100px、圆角 8px、间隔 8px；手机可露出下一张的一部分提示横向滑动，桌面提供前后切换按钮。交互区域只在照片条内部横向移动，不劫持整页上下滚动。

头像和缩略图使用等比裁切，不拉伸；裁切焦点由管理员调整。既有衍生图及顺序见 `design-references/2026-10-29-Linktree-御姐风/用户照片组/裁切与顺序.json`。管理页可预览裁切结果，修改草稿不立即替换公开版本。

## 6. 成年确认状态与转移

成年确认页展示“顾清棠”“仅限成年人”“请确认你已年满 18 岁。”，按钮为“我已年满 18 岁”和“离开”。对应字段为 `SITE_NAME`、`AGE_TITLE`、`AGE_NOTICE`、`AGE_CONFIRM_LABEL`、`AGE_EXIT_LABEL`。初始功能文案已整理，待用户评审；后续可在后台编辑，发布校验保留明确的自主声明语义。

| 状态 | 可见内容与动作 | 后续状态 |
|---|---|---|
| 首次访问 | 纯文字成年确认，不显示头像、照片或主页入口 | 确认进入处理中；离开进入退出路径 |
| 确认处理中 | 确认按钮显示处理中并避免重复提交；保留可理解的反馈 | 成功进入主页；失败回到确认页并显示可重试提示 |
| 有效期内 | 进入已发布主页，页脚提供重新确认入口 | 到期或手动清除后回到确认页 |
| 30 天到期 | 回到成年确认页，使用状态提示说明需重新确认 | 重新确认后建立新的固定期限 |
| 手动清除 | 清除成年状态后回到确认页，焦点放到页面标题 | 后续依首次流程 |
| 存储受限 | 确认后当前标签页可浏览，显示状态不会跨访问保留的提示 | 页面结束清除；刷新或新页面可重新确认 |
| 已选择离开且目标有效 | 跳往已配置的中性目标，不写入确认状态 | 访问外部页面 |
| 已选择离开且目标为空 | 显示“离开页面暂不可用，请返回确认页。”的纯文字退出状态，不展示主页 | 提供返回确认的明确操作 |

记忆从首次成功确认时刻开始固定 30 天，即 2,592,000 秒；再次访问不滚动续期。同浏览器、同站点有效，跨设备、跨浏览器、无痕窗口不共享。存储受限凭据只保留于当前标签页内存，避免刷新后反复自动跳转的循环。

实现标注：确认前不请求、预取或返回主页配置及受控媒体；内容隔离落实到数据与媒体访问。成年凭据与管理员会话独立，管理员预览走管理员权限。设计中的原型连线仅表达转移，不代表已完成服务器校验、Cookie 或缓存控制。

## 8. 管理员后台与编辑流程

后台使用清楚的中文字段名与帮助文字；未填字段显示“未填写”等帮助文字，公开可选缺项隐藏，空目标禁用或隐藏。帮助文字不作为实际字段值保存。导航分为基础信息、成年确认、五个入口、照片、补充信息／页脚、状态文案及账号。手机采用可换行的分区入口或单列选择，不让整个页面横向滚动。

| 画面／状态 | 设计反馈与行为 |
|---|---|
| 登录默认 | 账号、密码、登录；密码可见切换有文字标签；无公开默认凭据 |
| 登录错误 | 表单级错误，保留账号，焦点移至提示；不逐项透露账号是否存在 |
| 请求受限 | 说明暂后重试，保留输入；重试时间采用后端返回值，设计不编造固定倒计时 |
| 会话到期 | 登录提示及可返回的编辑位置；敏感修改先要求重新登录 |
| 未改动 | 显示当前已发布或草稿版本信息；动作状态明确 |
| 未保存 | 标记有未保存变更；保存草稿可用；离开触发确认 |
| 保存中 | 防重复提交，保留编辑内容；不提前显示成功 |
| 保存成功 | 显示已保存草稿及时间；公开版本保持原状 |
| 保存失败 | 保留表单输入，说明失败并允许重试 |
| 草稿预览 | 使用与公开页相同布局，带管理员专属预览标识；返回编辑位置 |
| 发布校验失败 | 顶部错误摘要与字段内错误对应；跳到第一个错误字段 |
| 发布中 | 明确处理中，避免重复发布；公开页继续使用原成功版本 |
| 发布成功 | 显示成功版本与时间；提供查看已发布页面入口 |
| 发布失败 | 草稿保留，公开页继续原版本；显示可重试反馈 |

管理路径：登录 → 分区编辑 → 保存草稿 → 预览 → 发布校验 → 发布结果。预览本身不发布；修改内容也不自动影响公开页。所有公共内容、链接目标和照片引用在发布时作为同一配置版本切换。

发布校验至少覆盖成年提示与确认语义、离开行为、联系信息、至少一个有效入口；HTTPS 地址格式、空地址、占位地址及停用状态具有独立校验。五入口允许分别排序、隐藏或停用；未就绪的会员 Bot 保持禁用或隐藏。

未保存离开弹层提供“继续编辑”和“放弃本次未保存修改”；默认焦点在保留编辑内容的操作。删除图片、停用主入口时说明影响并明确确认对象。密码修改、退出和凭据重置后的旧会话失效由后续实现验证。

## 9. 键盘、焦点与反馈

- 页面按视觉顺序进入键盘顺序：主要操作 → 链接列表 → 照片控件 → 补充信息 → 页脚。后台按分区导航、字段、操作依次排列。
- 所有可操作控件最小触控区域为 44×44px；可见焦点环不被圆角容器裁切。照片位置点视觉可小，但点击区域仍满足最小尺寸。
- 链接使用链接语义，按钮使用按钮语义；Enter 激活链接与按钮，Space 激活按钮。禁用和隐藏状态均无真实跳转。
- 弹层打开后焦点进入弹层，Tab 约束在弹层内，关闭后回到触发控件；Escape 关闭非强制弹层并保留编辑。成年确认是页面流程，Escape 不视为确认。
- 每个字段关联固定标签、帮助与错误文字；错误摘要链接到具体字段。输入框占位文字不替代标签。
- 保存／发布结果使用可被辅助技术感知的状态提示；重大失败同时保留持久文字，不只依赖短暂 toast。
- 图片设置有意义的替代文本；装饰图标不重复朗读标签。外链告知将打开外部平台，桌面新标签页与移动端行为按需求处理。
- `prefers-reduced-motion` 下移除位移动效；默认照片手动切换，无持续动画和自动播放。

## 11. M1 交付检查与后续衔接

| 检查项 | 核对方式 |
|---|---|
| 方向、名称与内容结构一致 | 对照风格01视觉来源、需求 v3.5、当前文案配置与本文件 |
